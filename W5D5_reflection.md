# W5D5 — Reflection

## Reflection

A design system helps an organisation maintain consistency across digital products. In a real Indian organisation, reusable design tokens and components can help designers and developers work faster and reduce inconsistencies. A shared system for colors, typography, spacing, buttons, inputs, and cards makes the product easier to maintain and scale. Accessibility should also be considered when building reusable components so that the same standards are followed throughout the product. For SnapBook, the design system provides a consistent visual foundation and helps create reusable UI components that can be used across the photographer booking experience.

## Key Concept

The most important thing I learned is that a design system is more than a collection of UI components. It provides shared rules, tokens, components, and guidelines that help a team build consistent and scalable user experiences.
