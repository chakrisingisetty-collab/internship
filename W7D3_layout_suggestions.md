# W7D3 — SnapBook AI Layout Suggestions

## Objective
Explore three layout options for the SnapBook photographer discovery and booking screen.

## Option 1: Vertical List Layout
- Display photographers in a vertical list.
- Show photographer photo, name, rating, starting price, and a View Profile button.
- Keep filters at the top of the screen.
- Best for comparing photographer details in a simple format.

## Option 2: Two-Column Grid Layout
- Display photographer cards in a two-column grid.
- Include profile image, name, rating, price, and a View Profile button.
- Provide filters for photography type, location, price, and availability.
- Best for browsing multiple photographers efficiently.

## Option 3: Filter Sidebar with Results
- Display filters in a left sidebar.
- Show photographer results on the right.
- Include sorting options for price, rating, and availability.
- Keep essential booking information visible on each card.
- Best for users who need to compare several photographers using multiple filters.

## Accessibility Considerations
- Use readable text and sufficient colour contrast.
- Provide clear labels for buttons and filters.
- Ensure keyboard navigation and visible focus states.
- Do not communicate ratings or booking status through colour alone.

## Recommendation
The two-column grid is a suitable starting point for SnapBook because it allows users to browse multiple photographers and compare key details. Validate this choice through usability testing before finalising the layout.
