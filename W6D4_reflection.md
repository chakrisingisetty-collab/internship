# W6D4 — Reflection

## 1. Key Learnings

I learned how to prepare a usability test plan for the Cynaris onboarding flow. I understood how to define test objectives, identify target users, create realistic user tasks, and select success metrics. I also learned the importance of observing user behavior and collecting feedback to identify usability problems.

## 2. Practical Application

In a real organization, usability testing helps teams understand whether users can complete important tasks without confusion. For example, testing an onboarding flow can reveal unclear form labels, confusing validation messages, and missing instructions. These findings help the design team improve the user experience.

## 3. Challenge

The main challenge was creating user tasks and observation criteria that clearly measure the usability of the onboarding process.

## 4. Improvement

I would conduct usability sessions with actual participants, record task completion times and errors, and use their feedback to prioritize improvements.

## 5. Key Concept

**Usability Testing:** A method of evaluating a product by observing users as they perform tasks to identify usability problems and improve the overall experience.

## 6. Practical Template

For each usability session, record:
- Participant ID
- Task assigned
- Task completed: Yes/No
- Time taken
- Errors or difficulties
- Help required
- Participant feedback
- Recommended improvement

## 7. Conclusion

Preparing this test plan helped me understand how structured usability testing can identify onboarding issues and guide user-centered design improvements.
