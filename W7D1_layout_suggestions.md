napBook – Photographer Search & Comparison
(Three distinct layout concepts – all keep a clean, modern look with 8‑dp spacing grid, Roboto / Inter, 16 sp body, 20 sp headings, WCAG‑AA contrast)
1️⃣ Layout A – Vertical List with Sticky Header
Element	Placement & Details
Header & navigation	Fixed at the top (height 56 dp). Left‑aligned back arrow, centered app title “SnapBook”, right‑aligned icon for “Favorites”.
Search & filter	Directly below the header, full‑width search bar (rounded, 48 dp height). To the right of the bar, a “Filter” icon that opens a slide‑up panel.
Photographer cards	Stacked vertically, each card occupies full width with 16 dp side padding.
• Image: Top‑half of the card – 16:9 hero photo, left‑aligned.
• Info column (below image): name, event specialty tags, and brief tagline.
Package price & services	Inside the same card, a horizontal bar under the info column: Price (large bold) on the left, a “· Includes X services” text on the right (smaller, secondary).
Ratings, reviews, availability	Row below the price bar: ★ 4.8, “(124 reviews)”, and a small calendar icon + “Next slot: 12 Oct”. All left‑aligned, spaced 8 dp.
Primary booking button	Sticky at the bottom of the screen (height 56 dp, full‑width, primary accent colour). Text: “Book Now”. The button appears only after a card is tapped (expands to show details).
Advantages	• Simple scanning – users scroll top‑to‑bottom, familiar list pattern.
• Easy for low‑vision users (large tap targets, clear hierarchy).
• Sticky header keeps search always reachable.
Best for	Quick, linear browsing when users prefer to read each photographer’s full mini‑profile before deciding.


2️⃣ Layout B – Two‑Column Grid with Persistent Filters
Element	Placement & Details
Header & navigation	Standard top bar (56 dp) with hamburger menu on the left, “SnapBook” centered, and a “Profile” avatar on the right.
Search & filter	Collapsible filter pane on the left side (width 240 dp) that stays visible on tablets/large phones; on small screens it slides over.
Search bar sits at the top of the pane, followed by check‑boxes (Event type, price range, rating).
Photographer cards	Grid: 2 columns on phones, 3 on tablets. Each card is a square (120 dp padding).
• Image: Top‑half, clipped to a 1:1 thumbnail.
• Overlay (bottom of image): photographer name in bold, event tags in chips.
Package price & services	Below the image, a compact text line: ₹12,500 (bold) – “Basic + 2 hrs + prints”. Uses secondary colour for the service list.
Ratings, reviews, availability	Small row under price: ★ 4.6 • 98 rev • “Available 3 days/week”. Icons sized 16 dp, left‑aligned.
Primary booking button	Inside each card, at the bottom right corner, a pill‑shaped “Book” button (primary colour, 36 dp height). Appears on hover/tap; otherwise hidden to keep the card tidy.
Advantages	• Side‑by‑side comparison – users can see multiple photographers at once.
• Persistent filters reduce context‑switching.
• Grid works well on landscape or tablet displays.
Best for	Users who want to compare visual styles quickly (e.g., wedding vs. birthday aesthetic) without scrolling through long lists.


3️⃣ Layout C – Horizontal Carousel + Detail Pane
Element	Placement & Details
Header & navigation	Minimal top bar (48 dp) with back arrow left, “Photographers” centered, and a “Sort” icon right. No persistent bottom nav.
Search & filter	Search bar placed above the carousel, full‑width with a subtle outline. Filter icon sits inside the bar on the right, opening a modal sheet.
Photographer cards	Horizontal carousel (swipe left/right). Each slide shows a large hero image (full‑width, 200 dp height) with a subtle gradient overlay. Below the image, a detail pane (fixed height 180 dp) slides up when the card is centered.
Package price & services	Inside the detail pane: price on the left (large, primary colour), a vertical list of 2–3 key services on the right (icons + short labels).
Ratings, reviews, availability	Directly under price/services: a single line – ★ 4.9 • 210 reviews • “Next open: 15 Oct”. Center‑aligned, easy to read at a glance.
Primary booking button	Fixed at the bottom of the screen (outside carousel) – full‑width, 48 dp tall, labelled “Book [Photographer Name]”. The button updates its label dynamically as the carousel changes.
Advantages	• Very visual – ideal for showcasing portfolio images.
• Reduces scrolling; users can swipe through options rapidly.
• Dynamic button reinforces the selected photographer, minimizing accidental bookings.
Best for	Users whose primary decision factor is visual style (e.g., comparing lighting, composition) and who like a magazine‑like browsing experience.


📊 Recommendation – Layout B (Two‑Column Grid with Persistent Filters)
Why it’s the fastest for comparison:
1. Side‑by‑side view – multiple thumbnails are visible simultaneously, letting users spot differences in portfolio style, price, and ratings without extra taps.
2. Persistent filters – users can tweak budget or event type and see the results update instantly, keeping the mental context intact.
3. Compact card design – all key data (price, services, rating, availability) lives on the card, so a single glance is enough to rank options.
4. Scalable – works equally well on phones (2‑column) and larger screens (3‑column), ensuring consistency across devices used in India’s diverse market.
If the product later wants a more visual‑first experience (e.g., for premium wedding packages), Layout C can be added as an optional “Explore” mode, while Layout A remains for users who prefer a linear list. But for the core “compare quickly” task, Layout B delivers the highest efficiency and conversion potential.
