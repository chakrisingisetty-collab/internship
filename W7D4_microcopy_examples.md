# W7D4: SnapBook Microcopy Examples

## 1. Call-to-Action (CTA) Buttons

| Situation | Microcopy |
|---|---|
| Start booking | Book a Photographer |
| Search results | Find Photographers |
| View photographer profile | View Portfolio |
| Confirm a booking request | Submit Booking Request |
| View existing bookings | My Bookings |
| Return to results | Back to Photographers |

## 2. Form Field Hints

| Field | Placeholder or Helper Text |
|---|---|
| Event type | Select an event type |
| Event date | Choose your event date |
| Location | Enter your event location |
| Duration | Select the number of hours |
| Budget | Enter your budget (₹) |
| Special requests | Tell us what you need (optional) |

## 3. Validation and Error Messages

| Situation | Message |
|---|---|
| Required field missing | Please complete this field. |
| Invalid event date | Please choose a valid event date. |
| Location missing | Enter your event location to continue. |
| No search results | No photographers found. Try another location or date. |
| Network problem | We couldn't load photographers. Please try again. |

## 4. Success and Confirmation Messages

| Situation | Message |
|---|---|
| Booking request submitted | Your booking request has been submitted! |
| Profile updated | Your profile has been updated successfully. |
| Saved photographer | Photographer added to your favourites. |
| Request failed | We couldn't submit your request. Please try again. |

## 5. Empty and Loading States

### Empty State
**Title:** No bookings yet

**Description:** Your next memorable moment starts here. Find a photographer for your event.

**CTA:** Explore Photographers

### Loading State
**Message:** Finding photographers for your event...

## 6. Tone and Consistency Rules
1. Use action verbs in button labels.
2. Keep messages short and specific.
3. Explain what went wrong and how to recover.
4. Use the same terms across all screens.
5. Avoid technical jargon and blame-oriented language.

## 7. How to Evaluate the Microcopy
- **Clarity:** Can users understand the message immediately?
- **Consistency:** Does the wording match the SnapBook brand voice?
- **Accessibility:** Is the language simple and understandable?
- **Usefulness:** Does the message help users take the next step?

## Conclusion
Consistent microcopy makes the SnapBook booking journey clearer, friendlier, and easier to complete.
