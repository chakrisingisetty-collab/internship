# W6D3 — Reflection

Affinity mapping is useful for understanding user needs and improving digital products. In an Indian organisation, such as an IT company or a startup, UX designers can collect feedback from users and group similar observations into themes. For SnapBook, the three themes are Trust & Credibility, Pricing & Package Information, and Booking Experience. These themes help identify the problems users face when selecting a photographer. The priority insight is to make photographer packages, prices, and included services easier to compare. This approach supports evidence-based design decisions and helps create a simpler, more user-friendly booking experience.

## Key Concept

Affinity mapping groups similar user research findings into themes to identify patterns, insights, and design opportunities.

## Practical Template

**Observation:** What did the user say?

**Theme:** Which category does it belong to?

**Insight:** What user need or problem does it reveal?

**Design Opportunity:** How might we improve the experience?
