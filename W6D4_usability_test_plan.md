# W6D4 — Usability Test Plan

## Project
Cynaris Onboarding Flow

## Testing Method
Moderated Usability Testing

## Participants
3 users

## Duration
10–15 minutes per participant

## 1. Test Objective
Evaluate whether new users can understand and complete the onboarding process easily, identify usability issues, and discover areas for improvement.

## 2. Target Users
- New users joining the Cynaris platform
- Users unfamiliar with the onboarding process
- Users accessing the platform for the first time

## 3. User Tasks
1. Find the registration or sign-up option.
2. Complete the required onboarding information.
3. Identify any required fields or validation messages.
4. Find the next step after submitting the information.
5. Complete onboarding and locate the main dashboard.

## 4. Success Metrics
- Task completion rate
- Time taken to complete each task
- Number of errors or difficulties
- Requests for assistance
- User satisfaction and feedback

## 5. Observation Checklist
- Can the user find the sign-up option?
- Are form labels and instructions clear?
- Can the user identify required fields?
- Are error messages understandable?
- Can the user identify the next step?
- Can the user reach the dashboard successfully?

## 6. Post-Test Questions
1. Was the onboarding process easy to understand?
2. Which step was the most confusing?
3. Were the instructions and error messages clear?
4. What would you improve?
5. How satisfied were you with the experience?

## 7. Expected Outcome
Identify onboarding usability problems and recommend improvements that make registration clearer, faster, and easier to complete.
