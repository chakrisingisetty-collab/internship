# SnapBook — UX Design Capstone

## 1. Design Challenge

How might we make it easier for users to discover trusted photographers, compare packages, and complete a photography booking with confidence?

## 2. Problem

Users often need to compare photographer portfolios, packages, pricing, ratings, and availability across different sources. This can make the booking process confusing and time-consuming.

SnapBook aims to provide a simple and trustworthy experience where users can discover photographers, explore portfolios, compare packages, select a date, and complete a booking in one place.

## 3. User Research

Two user interviews were conducted to understand how users discover and select photographers.

The research focused on:
- How users find photographers
- What information they check before booking
- What makes them trust a photographer
- Problems faced while comparing photographers
- What would make online booking easier

## 4. Research Insights

The main user needs identified were:

- **Trust** — Users want to see portfolios and reviews.
- **Clarity** — Users need clear information about packages and pricing.
- **Control** — Users want easy date and package selection.
- **Confidence** — Users need a transparent booking process.

## 5. User Flow

Home  
↓  
Explore Photographers  
↓  
Photographer Details  
↓  
View Portfolio

Select Package  
↓  
Choose Date  
↓  
Booking Details

The goal was to reduce unnecessary steps and make the booking journey easy to understand.

- Poppins — Headings

The design uses reusable components to maintain consistency throughout the experience.

## 9. Interaction Design

The prototype includes micro-interactions such as:

- Button press feedback
- Loading states
- Success feedback
- Error feedback
- Toggle interactions

These interactions provide clear feedback and help users understand the status of their actions.

## 10. Usability Testing

A think-aloud test was planned with one peer to evaluate the booking experience.

### Test Task

Find a photographer, review the portfolio, select a package, choose a date, and reach the booking confirmation screen.

### Areas Observed

- Navigation clarity
- Photographer information
- Package comparison
- Date selection
- Booking confirmation

## 11. Testing Findings

The usability evaluation focused on identifying areas where users could experience confusion during the booking process.

Key areas for improvement:
- Make package comparison more prominent.
- Make photographer availability easier to understand.
- Make booking status more visible.

## 12. Accessibility

Accessibility was considered throughout the design process.

The design includes:
- Better colour contrast
- Minimum 44×44px touch targets
- Clear focus states
- Visible form labels
- Descriptive labels
- Alt-text guidance
- Skip navigation

## 13. Improvements

Based on the usability evaluation, the next improvements would include:

- Improve package comparison
- Make availability more prominent
- Improve booking status feedback
- Conduct additional usability testing
- Collect feedback from more users

## 14. Outcome

The final SnapBook experience provides a structured way for users to discover photographers, explore portfolios, compare packages, and complete bookings.

Design outcomes:
- Clear photographer discovery
- Easy package comparison
- Simple booking flow
- Consistent visual design
- Reusable components
- Accessible interaction patterns

## 15. Learnings

This capstone helped me understand the complete UX design process from problem definition and research to user flow, wireframes, high-fidelity design, prototyping, usability testing, and iteration.

It also helped me understand the importance of validating design decisions with users instead of relying only on assumptions.
