# SnapBook — Component Behaviour Specification

## 1. Search Input

### Default
Displays the search placeholder.

### Focused
Shows a visible focus state.

### Typing
User can enter a search keyword.

### Error
Displays an error message when the input is invalid.

### Disabled
Prevents user interaction.

---

## 2. Book Now Button

### Default
Displays the primary booking action.

### Pressed
Provides visual feedback when the user taps the button.

### Disabled
Prevents interaction when the action is unavailable.

### Loading
Displays a loading indicator while the booking request is processed.

### Success
Navigates to the booking confirmation.

---

## 3. Bottom Navigation

### Default
Displays Home, Search, Bookings, Favorites and Profile.

### Active
Highlights the currently selected section.

### Inactive
Other navigation items remain visually neutral.

### Trigger
User taps a navigation item.

### Behaviour
The selected section opens and the active navigation state updates.
