# W6D1 — User Research: Photographer Booking

## Project
SnapBook

## Feature
Photographer Booking

## Participants
2 Users — Rahul and Priya

---

## 1. User Interview Questions

1. How do you currently choose a photographer for an event?
2. What information do you need before booking a photographer?
3. What problems do you face while comparing photographers?
4. What would make the booking process easier for you?
5. What would make you trust a photographer before booking?

---

## 2. Interview Findings

### User 1 — Rahul

- Checks photographer portfolio and reviews first.
- Wants package price and included services clearly.
- Finds it difficult to compare multiple photographers.
- Wants a simple booking process.
- Trusts photographers with verified reviews.

### User 2 — Priya

- Usually asks friends for photographer recommendations.
- Needs date availability and package details.
- Comparing prices takes too much time.
- Wants availability and booking confirmation in one place.
- Prefers verified photographers with previous work.

---

## 3. Affinity Map — 3 Themes

### Theme 1 — Trust & Credibility

- Verified reviews are important.
- Previous work builds trust.
- Users prefer recommended photographers.

### Theme 2 — Pricing & Information

- Clear package prices are needed.
- Users want included services.
- Date availability should be visible.

### Theme 3 — Booking Experience

- Comparing photographers takes time.
- Users want a simple booking process.
- Availability and confirmation should be in one place.

---

## 4. How Might We Statements

1. How might we help users quickly find trusted photographers?
2. How might we make photographer packages and prices easier to compare?
3. How might we show photographer availability clearly?
4. How might we make the booking process simple and fast?
5. How might we help users feel confident before confirming a booking?

---

## 5. Priority for Redesign

### Selected HMW

How might we make photographer packages and prices easier to compare?

### Reason

Users mentioned that comparing photographers and prices takes too much time. Making package information clearer and easier to compare can reduce user effort and support faster booking decisions.

---

## 6. Research Outcome

The research identified three key areas for improvement:

- Trust & credibility
- Pricing & information
- Booking experience

The priority opportunity is improving package and price comparison during the photographer booking process.
