# W5D5 — Cynaris Design System V1

## Project
SnapBook

## Design System Overview

The SnapBook design system provides reusable design tokens and UI components to maintain consistency across the application.

## 1. Design Tokens

### Colors

- Primary: #6C5CE7
- Background: #F8F9FC
- Text: #1F2937
- Secondary: #6B7280
- Success: #16A34A
- Error: #DC2626
- Warning: #D97706

### Typography

- Heading Font: Poppins
- Body Font: Inter

### Spacing

The design system follows an 8px spacing grid for consistent layout and spacing.

## 2. Components

The reusable component library includes:

- Button
- Input
- Card

Components include reusable variants and states to maintain consistency across the application.

## 3. Accessibility

Accessibility checks were performed using Storybook and axe-core.

- Button: 0 violations
- Input: 0 violations
- Card: 0 violations after fixing the color contrast issue

The Card category text color was updated to improve WCAG 2.1 AA contrast compliance.

## 4. Usage Guidelines

- Use design tokens instead of hardcoded values.
- Reuse existing components wherever possible.
- Maintain consistent spacing and typography.
- Follow accessibility guidelines when creating or modifying components.
