# W8D1: Heatmap Analysis — Cynaris Portal UX

## 1. Objective
Identify potential drop-off points in the Cynaris learning portal and recommend improvements to help users complete their tasks.

## 2. User Flow Analysis

### Flow 1: Login / Registration
**User goal:** Log in or register successfully.

**Potential friction points to investigate:**
- Form validation errors are unclear.
- Required fields are not clearly indicated.
- The primary action button is difficult to find.

**Evidence status:** These are hypotheses to validate. Actual heatmap data or user research findings have not yet been collected.

**Suggested improvement:**
- Use clear field labels and helpful validation messages.
- Make the primary action visually prominent.
- Show clear success and error states.

### Flow 2: Lesson / Quiz Completion
**User goal:** Complete a lesson and submit the quiz.

**Potential friction points to investigate:**
- The quiz link is difficult to locate.
- The lesson completion action is unclear.
- Users receive insufficient feedback after quiz submission.

**Evidence status:** These are hypotheses to validate. Actual portal analytics or user research findings have not yet been collected.

**Suggested improvement:**
- Make the next action easy to identify.
- Display quiz submission confirmation.
- Clearly show lesson progress and completion status.

## 3. Metrics to Collect
- Login and registration completion rate.
- Number of users starting and completing a quiz.
- Clicks on key buttons.
- Scroll depth on important pages.
- Form errors and task completion time.

## 4. Before-and-After Redesign Plan
For each flow, create at least three screens in Figma.

### Flow 1
1. Before: Existing login or registration screen.
2. After: Improved form with clearer labels and validation.
3. After: Success confirmation screen.

### Flow 2
1. Before: Existing lesson page.
2. After: Improved lesson page with a prominent quiz action.
3. After: Quiz result and lesson completion confirmation.

Use actual screenshots of the portal for the before designs.

## 5. Developer Handoff
- Use consistent spacing based on an 8px grid.
- Document colour tokens and typography.
- Define default, hover, focus, disabled, error, and success states where applicable.
- Ensure keyboard accessibility and readable contrast.

## 6. Validation Plan
Ask two people to complete the selected tasks using the redesigned screens. Record where they hesitate, any errors, and whether they complete each task.

## 7. Key Learning
Heatmaps help designers understand interaction patterns. Combining heatmaps with task completion data and user feedback helps identify potential usability problems. Design changes should be validated rather than based on assumptions alone.
