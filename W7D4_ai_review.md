# W7D4: AI Copywriting Review

## Project
SnapBook — Photographer Booking Application

## AI-Assisted Microcopy Review

### 1. Primary Call-to-Action
**Suggested copy:** Find Photographers

**Review:** The label is short, action-oriented, and explains what happens when the user clicks the button.

### 2. Form Helper Text
**Suggested copy:** Select your event date.

**Review:** This instruction is simple and tells users what information is required.

### 3. Validation Message
**Suggested copy:** Please select a valid event date.

**Review:** The message identifies the problem clearly. The interface should place it near the date field.

### 4. Empty State
**Suggested copy:** No bookings yet. Find a photographer for your next special moment.

**Review:** This message explains the current state and encourages the user to take the next step.

### 5. Success Message
**Suggested copy:** Your booking request has been submitted!

**Review:** This confirms the action. The application should display this message only after successful submission.

## Quality Checklist

- [x] Clear and concise wording
- [x] Action-oriented button labels
- [x] Helpful error messages
- [x] Consistent and friendly tone
- [x] Suggested next steps for empty states
- [x] Success message tied to the correct application state

## Limitations and Validation

AI-generated copy is a starting point, not a final decision. A designer should check brand consistency, accessibility, accuracy, and user comprehension. Suggested text should be tested with representative users before release.

## Conclusion

AI can accelerate microcopy creation, but human review ensures that the final text is useful, accurate, and appropriate for the product.
