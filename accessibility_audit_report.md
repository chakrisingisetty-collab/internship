# SnapBook — Accessibility Audit Report

## Objective

The objective of this audit was to identify and improve accessibility issues in the SnapBook Home screen based on WCAG 2.1 AA accessibility principles.

## Accessibility Issues Identified

### 01 — Contrast

Issue:
Some text elements had low contrast against the background.

Fix:
Improved text contrast to make the information easier to read.

### 02 — Touch Target Size

Issue:
The notification icon had a small interactive area.

Fix:
Increased the touch target to provide a larger and more accessible interaction area.

### 03 — Alt Text

Issue:
Informative images did not have documented alternative text.

Fix:
Added meaningful alt text guidance for informative images.

Example:
"Photographer holding a camera"

### 04 — Form Labels

Issue:
The search field relied mainly on placeholder text.

Fix:
Added a clear and persistent label for the search field.

### 05 — Focus State

Issue:
Interactive elements did not have a clearly visible focus state.

Fix:
Added visible focus indicators for keyboard navigation.

## Skip Navigation

Designed a "Skip to main content" component to help keyboard users quickly reach the main content.

## Accessibility Annotation Guide

The design includes developer annotations for:

- Contrast
- Touch Target Size
- Focus State
- Alt Text
- Form Labels

## WCAG 2.1 AA

The design was reviewed using the principles of:

- Perceivable
- Operable
- Understandable
- Robust

## Conclusion

The SnapBook Home screen was audited and improved to create a clearer, more inclusive, and accessible user experience.
