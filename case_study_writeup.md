# SnapBook — Photography Booking & Management Experience

## Overview

SnapBook is a photography booking and management experience designed to help users discover photographers, explore portfolios, compare packages, and complete bookings with confidence.

This project was created as part of my UI/UX design internship. I worked on the complete design process, including problem identification, research, ideation, visual design, interaction design, accessibility, and design system development.

**Role:** UI/UX Designer  
**Tool:** Figma  
**Project Type:** Internship Project

## Problem

Finding and booking a professional photographer can be difficult because users need to compare portfolios, packages, pricing, ratings, and availability across different sources.

The design challenge was to create a simple, clear, and trustworthy experience that helps users discover photographers and complete bookings easily.

## Research

The research focused on understanding what users need when selecting a photographer.

The main user needs identified were:

- **Trust** — See portfolios and reviews
- **Clarity** — Understand packages and pricing
- **Control** — Choose dates and packages easily
- **Confidence** — Receive clear booking information

## User Flow

Home → Explore Photographers → Photographer Details → View Portfolio → Select Package → Choose Date → Booking Details → Confirm Booking

## Ideation

I explored solutions for photographer discovery, category navigation, photographer cards, package comparison, and the booking flow.

The main design principles were:

- Simplicity
- Clarity
- User Control
- Consistency

## Visual Design

**Primary:** #6C5CE7  
**Background:** #F8F9FC  
**Text:** #1F2937  
**Secondary:** #6B7280  
**Success:** #16A34A  
**Error:** #DC2626  
**Warning:** #D97706

Poppins was used for headings and Inter for body text. Reusable UI components were created to maintain consistency.

## Interaction Design

The interface includes button press feedback, loading states, success feedback, error feedback, and toggle interactions.

## Accessibility

Key improvements included better colour contrast, minimum 44×44px touch targets, clear focus states, visible form labels, descriptive labels, alt-text guidance, and skip navigation.

## Outcome

The final SnapBook experience provides a structured way for users to discover photographers, compare packages, explore portfolios, and complete bookings.

- Clear photographer discovery
- Easy package comparison
- Simple booking flow
- Consistent visual design
- Reusable components
- Accessible interaction patterns

## Learnings

Working on SnapBook helped me understand the complete UX design process, from identifying a user problem and researching needs to designing interfaces, creating reusable components, improving accessibility, and preparing designs for handoff.
