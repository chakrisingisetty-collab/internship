# W8D2: Onboarding Flow Redesign

## Project
Cynaris Learning Portal UX Redesign

## Screen 1: Welcome
- Add a clear heading and primary action.
- Make the next step easy to understand.

## Screen 2: Registration Details
- Use clear field labels and required-field indicators.
- Show helpful validation messages.

## Screen 3: Success and Next Step
- Display a registration success message.
- Provide a clear button to open the learning dashboard.

## Design Guidelines
- Use consistent 8px spacing increments.
- Keep colours and typography consistent.
- Define focus, hover, disabled, error, and success states.
- Check text contrast and mobile responsiveness.

## Validation
Ask two people to test the flow and record their feedback.

## Key Learning
Good onboarding guides users clearly, reduces unnecessary effort, and provides feedback at each important step.
