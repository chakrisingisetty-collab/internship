# SnapBook — Asset Export Guide

## Icons

Format: SVG  
Size: 24×24 / 48×48  
Usage: Navigation and interface icons.

## Images

Format: PNG  
Export: 1x / 2x / 3x  
Usage: Photographer and location images.

## Backgrounds

Format: WebP  
Usage: Large background images.

## Logos

Format: SVG / PNG  
Usage: SnapBook logo and branding.

## Naming Convention

- icon-search.svg
- icon-calendar.svg
- photographer@1x.png
- photographer@2x.png
- photographer@3x.png
- location-hyderabad@2x.png
- hero-banner.webp
- logo-snapbook.svg

## Export Checklist

- Correct format
- Correct resolution
- Clear file name
- Assets ready for development
