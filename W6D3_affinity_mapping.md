# W6D3 — Affinity Mapping & Insight Extraction

## Project Details
- **Project:** SnapBook
- **Feature:** Photographer Booking
- **Research Method:** User Interviews
- **Participants:** 2

## Theme 1: Trust & Credibility

### User Findings
- Users check photographer portfolios and reviews.
- Previous work helps users evaluate quality.
- Recommendations and verified information build trust.

### Insight
Users need reliable evidence of a photographer's quality before booking.

## Theme 2: Pricing & Package Information

### User Findings
- Users want clear package prices.
- Users need to understand which services are included.
- Comparing packages from different photographers takes time.

### Insight
Users need a consistent, easy-to-understand comparison of photographer packages and prices.

## Theme 3: Booking Experience

### User Findings
- Users want to check photographer availability.
- Comparing photographers takes time.
- Users prefer booking details in one place.

### Insight
Users need a simpler booking process with availability and essential details in one place.

## Priority Insight
Users need a clear way to compare photographer packages, prices, and included services.

## Design Opportunity
Create a photographer comparison section in SnapBook that displays package price, included services, availability, and reviews in a consistent format.

## Key Learning
Affinity mapping helps organize qualitative research findings into themes and identify important user needs. These insights help designers make informed, user-centered design decisions.
