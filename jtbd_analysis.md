\# SnapBook — Jobs-to-be-Done Analysis



\## 1. Find a Suitable Photographer



When I need a photographer for an event,

I want to quickly compare photographers, portfolios, prices, and availability,

so that I can choose a photographer who matches my requirements.



\## 2. Book a Photography Session



When I find a suitable photographer,

I want to select a date, time, package, and location,

so that I can confirm my photography booking easily.



\## 3. Manage My Booking



When I have already booked a photographer,

I want to view my booking details, status, and updates,

so that I know what is happening with my photography session.
