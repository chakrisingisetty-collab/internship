# W7D3 — SnapBook AI Colour Palette

## Objective
Create a five-colour palette for the SnapBook photography booking application.

## Brand Tone
Professional, trustworthy, modern, and accessible.

## Colour Palette

| Colour | Hex Code | Intended Use |
|---|---|---|
| Midnight Navy | #1A2B4C | Brand identity and headings |
| Soft Slate | #F5F7FA | Page backgrounds |
| Cool Charcoal | #4E5A66 | Secondary text |
| Accessible Gold | #8A6D00 | Accent text and highlights |
| Accessible Teal | #007777 | Interactive elements and links |

## Usage Guidelines
- Use Midnight Navy for important headings and primary brand elements.
- Use Soft Slate for light page backgrounds.
- Use Cool Charcoal for supporting text.
- Use Accessible Gold sparingly for accents.
- Use Accessible Teal for links and interactive elements.

## Accessibility Notes
Check each foreground and background combination using a WCAG contrast checker before implementation. Do not assume that a colour is accessible in every context.

## Conclusion
This palette provides a consistent visual direction for SnapBook. Contrast validation and usability testing should guide the final colour choices.
