# W7D4: SnapBook Microcopy Guide

## 1. Project Overview
SnapBook is a photographer booking application that helps users discover photographers and request bookings for events.

## 2. Goal
Create clear, helpful, and user-friendly text for buttons, form fields, validation messages, booking confirmations, and empty states.

## 3. Brand Voice
- **Friendly:** Use welcoming and natural language.
- **Clear:** Explain what users need to do.
- **Concise:** Keep messages short and easy to scan.
- **Helpful:** Explain how to fix errors instead of only showing a failure.

## 4. Booking Form Microcopy

| UI Element | Recommended Copy |
|---|---|
| Screen title | Book a Photographer |
| Event type | Choose your event type |
| Event date | Select your event date |
| Location | Enter your event location |
| Duration | How many hours do you need? |
| Primary CTA | Find Photographers |
| Secondary CTA | Cancel |
| Required field error | Please complete this field. |
| Invalid date error | Please select a valid event date. |
| Location error | Enter a location to find photographers near your event. |

## 5. Booking States

### Empty State
**Title:** No bookings yet

**Description:** Find a photographer for your next special moment.

**CTA:** Explore Photographers

### Success State
**Title:** Booking request submitted!

**Description:** Your request has been sent. You can check its status in My Bookings.

**CTA:** View My Bookings

### Loading State
**Message:** Finding photographers for your event...

## 6. Accessibility Guidelines
- Use simple, familiar words.
- Keep button labels descriptive and action-oriented.
- Do not communicate errors through colour alone.
- Place error messages close to the relevant fields.
- Ensure text is readable and has sufficient contrast.
- Use consistent terms throughout the booking journey.

## 7. Success Criteria
- Users understand the purpose of every field.
- Buttons clearly describe the next action.
- Error messages explain how to fix the problem.
- Confirmation messages explain what happens next.

## 8. Conclusion
Good microcopy reduces confusion, helps users complete booking tasks, and builds trust in SnapBook.
