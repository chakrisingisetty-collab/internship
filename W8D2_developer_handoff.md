# W8D2: Developer Handoff Checklist

## Layout and Spacing
- Use consistent spacing in 8px increments.
- Maintain alignment and consistent margins.

## Typography and Colours
- Document font sizes, weights, and colour tokens.
- Check text contrast and readability.

## Interaction States
- Default state
- Hover state
- Keyboard focus state
- Disabled state
- Error state
- Success state

## Responsive Design
- Check desktop and mobile layouts.
- Ensure buttons and form fields are easy to use.

## Testing
- Ask two people to test the onboarding flow.
- Record feedback and usability issues.

## Handoff Notes
- Link the Figma file.
- Add annotations for spacing and interactions.
- Document any unresolved questions.
